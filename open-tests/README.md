# Открытый набор тестов

Каждый тест состоит из двух файлов: `<testname>.in`, являющегося входным файлом, и `<testname>.out`, являющегося ожидаемым правильным выходным файлом.
Для запуска тестов можно воспользовать скриптом `run-tests.sh`. **Скрипт проверки работает только на Linux**.
Для запуска тестов необходимо в скрипт передать *скомпилированную* программу: `./run-tests.sh solution`.
Если все тесты успешно пройдены, то будет выведено:
```
Passed all 12 tests
```

Если какой-то тест не пройден, то выведется сообщение:
```
/tmp/tmp.IelbOIhpEd /tmp/open-tests/test1.out differ: byte 1066, line 2
FAIL: input=/tmp/open-tests/test1.in expected=/tmp/open-tests/test1.out prog_output=/tmp/tmp.IelbOIhpEd
```
где, `/tmp/open-tests/test1.in` -- путь до входного файла,
`/tmp/open-tests/test1.out` -- путь до ожидаемого файла,
`/tmp/tmp.IelbOIhpEd` -- путь до полученного файла

***Внимание***: прохождение открытого набора тестов не гарантирует полную корректность выполнения задания!
